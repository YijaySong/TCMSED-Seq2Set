# 固定的内部交叉验证协议

医院提供的记录覆盖 2010—2020 年，证候要素由医师依经验标注并经院方核验；这里按用户转述记录，不再进行词项审计或修改数据。现有文件只有 `id symptom Se` 三列，没有逐例日期或患者标识，因此本协议按**记录**划分，不能称为患者级或时间外验证。

此前的 2940/630/630 测试划分已在多轮模型选择中被查看。新三折划分用于检查固定方法在不同记录子集上的表现，属于开发后的内部交叉验证；它不会把这批已用于方法开发的数据变成全新独立队列。

## 划分与训练

- 原始文件：`../广安门心绞痛4200例.txt`，以 `splits/protocol.json` 中的 SHA-256 固定版本。
- 按真实证候要素个数分层，固定外层种子 20260928，生成三个互斥测试折；每条记录只进入一个测试折。
- 每个外层折有 1400 条测试记录；其余 2800 条中，按标签数分层抽取 420 条验证记录，留下 2380 条训练记录。内层抽样种子为 `20260929 + 折号(从0起)`。
- 每种方法运行训练种子 9、17、29，每次 100 轮，batch size 64。三折共九次训练；四种方法共 36 次训练。
- 相同折与种子下，各方法使用相同 ID 清单、症状/标签词表和训练预算。所有可学习预处理、先验统计、阈值及检查点选择只能使用该折训练或验证记录。外层测试标签只用于最后评价。
- 每轮按验证集完全匹配率选择检查点；并列时比较样本 F1，仍并列则选较早轮次。独立 sigmoid 方法在验证集搜索全局阈值 0.05 至 0.95、步长 0.01；阈值并列规则按完全匹配率、样本 F1、Micro-F1、较小阈值。空预测用最高分标签补足。其他模型的决策规则须在运行前写定。
- M03 将先固定具体模型、优化器、EMA/梯度裁剪、源码哈希和运行命令，再开始正式训练。不得根据外层测试结果改动候选模型或超参数后仍把同一轮称作预定比较。

## 结果汇总

每个方法、每个训练种子保存 4200 条折外预测，每条 ID 恰好出现一次。对这 4200 条记录计算该种子的完全匹配率、样本 F1、Micro-F1、Macro-F1 和基数 MAE，再报告三个种子的均值与样本标准差。另列各折成绩和按真实标签数分层的记录数及指标。

主要差值为同一记录上 GRU 完全匹配指示值减去对照方法的指示值。先对三个种子求病例级平均差值，再按记录有放回重采样 10,000 次，报告 95% 百分位区间；样本 F1 和基数 MAE 同法作次要比较。折与种子下的九个成绩有重叠训练集，不作为九个独立样本进行 t 检验。没有患者 ID 时，病例级区间不包含同一患者多次就诊的相关性。

旧 630 条测试集结果保留为模型探索记录，不与新三折结果拼接成单张主表。此次交叉验证若用于比较已经固定的候选方法，也只能称记录级内部验证。
